Netflix Content Dashboard

Project Overview
This project presents a Netflix Content Dashboard built in Tableau, designed to analyze Netflix’s catalog of movies and TV shows.

The dashboard provides a high-level overview of:

• The total number of Netflix titles
• Distribution between movies and TV shows
• Most common content genres
• Content ratings distribution

The goal of this project is to demonstrate data visualization, KPI design, and dashboard layout best practices while transforming raw Netflix data into clear, business-ready insights.

Key Insights
• Total Titles: 8,809
• Movies: 6,132 (69.6%)
• TV Shows: 2,677 (30.4%)
• Most common genres include Dramas, Comedies, and Action & Adventure
• The majority of content falls under TV-MA and TV-14 ratings

Dashboard Components
• KPI cards for Total Titles, Movies, and TV Shows
• Donut chart comparing Movies vs TV Shows
• Bar chart of Genres by Total Titles
• Content Ratings distribution

Tools Used
• Tableau Public
• Data Visualization & Dashboard Design
• Calculated Fields & KPIs
